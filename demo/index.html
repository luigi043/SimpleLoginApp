ANDROID LOGIN DEMONSTRATION

A small app.
A complete login flow.

Try input validation, open a demo profile, and log out. This browser companion follows the native Android app's flow.

Use sample credentials only.

This is an offline UI demonstration. It has no server authentication, registration, or real accounts. Never enter a real password.

Download Android APK ↗View source on GitHub

Debug APK for Android 7.0 or later. Install only if you trust the source. The browser stores a demo email and session time in this tab's session storage. Passwords are never saved or sent to a server.

What does the demo cover?

Login, required-field and invalid-input errors, incorrect credentials, profile, session restoration on refresh, password visibility, and logout confirmation. Closing this tab ends the browser session. Android saves its local session until logout or app data is cleared.

The APK is the native app. This page is a web implementation, not an Android emulator.
